# SYLO 🎵

**Transforming how friends discover, plan, and attend live music together.**

SYLO is a social-first concert discovery and coordination platform that solves the core problem of live music attendance: **proactive fatigue**. While music is streamed alone, concerts are experienced together—and SYLO makes it effortless to find shows, see which friends are interested, and coordinate group attendance.

---

## 🎯 The Problem

Current concert discovery and planning tools are fragmented and built for individuals, not groups:

- **Fragmented Discovery**: Fans miss shows due to algorithmic noise across Spotify, Ticketmaster, Songkick, Instagram, and newsletters
- **Invisible Interest**: Coordination happens via manual one-on-one outreach through group chats
- **Financial Risk**: Single buyers must front costs for entire groups or risk sellouts

**The Result**: 55% of Gen Z fans skip events because they had "no one to go with"

---

## ✨ The Solution

SYLO transforms concert planning into a unified social experience with three core features:

### 1. **Shared Discovery Feed**
A personalized feed showing:
- Artists you love based on your Spotify/streaming data
- Concerts your friends are interested in or attending
- Match ratings (e.g., "Your top artist on Spotify", "Match: 92%")
- Real-time friend activity ("Alex just bought tickets to Billie Eilish")

### 2. **Group Coordination**
- See which friends are interested or going at a glance
- Select multiple friends to start group chats or send nudges
- Built-in coordination eliminates app-switching and DM chaos

### 3. **Split Payments & Escrow**
- Instant cost splitting at checkout
- Escrow system where everyone contributes their share upfront
- Collect seat preferences from all party members
- No one acts as the banker or fronts the risk

## 📦 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/sylo.git
   cd sylo
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Install Tailwind CSS**
   ```bash
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```

4. **Start the development server**
   ```bash
   npm start
   ```

5. **Open your browser**
   Navigate to `http://localhost:3000`
